# WASDPad Hardware
## Revision 1.5

Status: In Design

Revision 1.5 is an enhanced version of the production-ready Revision 1.2 hardware platform.

The fundamental operating principle remains unchanged. Revision 1.5 focuses on improving reliability, serviceability and manufacturability.

## Planned Improvements

- Cherry MX compatible hot-swap sockets
- Resettable overcurrent protection
- ESD protection on external signal lines
- Improved status indication
- PCB routing and silkscreen cleanup
- Improved assembly and maintenance
- Updated manufacturing documentation

## Architecture

Revision 1.5 remains a fully hardware-based controller.

It does not contain:

- A microcontroller
- Firmware
- USB connectivity
- User profiles
- Programmable logic

Autofire remains implemented using the ICM7555 timer architecture inherited from Revision 1.2.

## Documentation

The Revision 1.5 hardware documentation includes:

- Bill of Materials

- Procurement notes
- Schematics
- PCB manufacturing files
- Assembly instructions
- Test procedures
