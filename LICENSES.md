# WASDPad Licensing Notes

This document describes the intended licensing model of the WASDPad project.
The project is currently under active development and no final license has been selected yet.

## Planned licensing

The following licensing model is currently being considered:

| Component | Planned License |
|----------|-----------------|
| Firmware | MIT License |
| Hardware (KiCad source) | CERN Open Hardware License v2 |
| 3D enclosure models | CC BY-SA 4.0 |
| Documentation | CC BY 4.0 |

These licenses are subject to change until the first public release.

## Trademarks

The Commodore "C=" logo is **not** covered by the project licenses.
Use of the logo is subject to separate permission from Commodore International.

See `TRADEMARKS.md` for details.
