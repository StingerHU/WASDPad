# WASDPad+ Rev1.5.2 - Enclosure Render Gallery

**Enclosure:** Sixth iteration, finalized  
**TPU wrist rest:** Experimental / near-final, physically fit-checked  
**Mechanical design:** Dester3D / Sándor Sebesi

The six views below are **original design renders** supplied with the project. They are not photographs of an assembled controller, and do not constitute dimensional or strength-test evidence. The additional overview graphics use only the supplied renders and measured part bounds.

## Lower base

| Interior / support side | Exterior / underside |
| --- | --- |
| ![Lower base internal PCB supports and structural reinforcement](images/wasdpad_bottom_interior.jpg) | ![Lower base underside with screw access locations](images/wasdpad_bottom_exterior.jpg) |

The internal surface contains support features for the electronics, while the underside shows the enclosure bottom and access features for the optional screw fastening. The project owner also identifies an underside brand/identification-label provision.

## Soft TPU wrist rest

| Wrist-contact side | Underside / mounting side |
| --- | --- |
| ![Soft black TPU wrist rest top surface](images/wasdpad_wrist_rest_top.jpg) | ![Wrist rest underside showing its mounting face](images/wasdpad_wrist_rest_underside.jpg) |

The black TPU accessory is secured to **three dedicated locations** on the lower housing. The project owner reports a comfortable, secure fit without rocking or relative sliding. The accessory remains experimental / near-final pending extended wear testing.
